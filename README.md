# ma-team-01 — plugin

Plugin Claude (Cowork / Claude Code) pour rédiger, contrôler et publier les posts sociaux d'un portefeuille de marques, **en français, dans le chat**. Google Drive est la source de vérité unique ; Buffer est le canal de publication.

Version publique et générique du plugin : aucun nom réel, la marque d'exemple est « Camille », la racine Drive par défaut est « Ma Team ».

## Installation

```
/plugin marketplace add alinusgallus/ma-team-01-plugin
/plugin install ma-team-01@ma-team-01
```

## Mise en route

1. Connecter **Google Drive** et **Buffer** dans les réglages (connecteurs), une fois.
2. « installe le système » → crée la racine Drive, la config, le Roster.
3. « ajoute la marque … » → contexte, canaux, arborescence.
4. Déposer 15–30 posts exemples par marque (le levier de qualité).
5. Prévoir des sujets, générer les brouillons, valider — les posts partent dans Buffer.

Détail complet des huit skills et des prérequis : [`ma-team-01/README.md`](ma-team-01/README.md).
